# Feature benchmark: leading commercial solutions

Fractodactyl is free and open source and will remain free. A leading commercial solution is an established reference for fractal creation and animation. Our ambition is to at least match the capabilities below and, where practical, exceed them in usability, rendering efficiency, and creative control.

This is a feature reference and statement of intent, not a claim of current parity or measured superiority. It does not set implementation order or replace the project's existing issue and decision process.

## Reference scope

Reviewed public manuals and feature descriptions of leading commercial solutions on 2026-10-17. The feature baseline below summarizes creative and production workflows without naming an individual product.

## Capabilities to match and improve upon

| Area | Commercial capabilities to use as a reference |
| --- | --- |
| Exploration | Deep zooming; pan, rotate, stretch and skew; interactive parameter previews. |
| Fractal definitions | Community formula library, formula plug-ins, custom formulas and a built-in compiler. |
| Styling | Coloring algorithms, editable and randomized gradients, transparency and image import. |
| Compositing | Layers, groups, masks, blend modes and reusable layer presets. |
| Animation | Independent parameter keyframes, timeline editing, interpolated camera and style changes, and previews. |
| Final output | High-resolution stills, image sequences, movie export, anti-aliasing and motion blur. |
| Render management | Background queues, concurrent jobs, pause/resume, restart recovery and job backup/restore. |
| Organization | Thumbnail browsers, saved parameter sets and file search. |
| Compute | Multicore rendering and distributed calculations across computers. |

Commercial editions commonly separate core rendering and deep zooming from layering, animation and distributed rendering features. Animation and long-running render management are established capabilities worth learning from.

Matching a capability means supporting the useful creative workflow; it does not require copying a commercial application's interface, formula language or file formats. Numerical quality, speed and usability need separate validation with representative projects.

## Fractodactyl experience goals

These are proposed directions, not a list of features already implemented.

- **Immediate enjoyment on the web:** open onto a beautiful interactive view; explore presets, change styles and enjoy real-time animation without installation.
- **Discovery:** explore manually or search for selected mathematical features; save exact locations and useful descriptions.
- **Style design:** create, preview, save and share looks.
- **Journey composition:** choose locations along a path, set camera and style keyframes, control timing and preview transitions.
- **Efficient journeys:** help estimate render cost and choose efficient paths and reusable computations. Preserve artistic intent and let users lock important locations and moments.
- **Desktop production:** support demanding video creation, batch exports and reliable multi-day rendering.
- **Continuity:** share a versioned project format between browser and desktop, preserving exact coordinates, styles and journey settings.
- **Sharing and education:** link YouTube zooms and explanations to the corresponding interactive locations, styles and journeys.

The website should be satisfying for someone who only wants to explore for a few minutes, while giving interested visitors a natural route into composition and desktop production.
