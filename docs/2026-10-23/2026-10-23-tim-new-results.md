# 2026-10-23 — Tim's new GPU results (so far, so good)

## Memo for the maintainer

Both RTX 3090s work with the new adapter selector: `fd adapter 1` maps to NVIDIA GPU0 and adapter 2 maps to GPU1, verified by observing the render process UUID in `nvidia-smi`. Each rendered the same 320x180, ss1, 100,000-iteration period-764 zone frame; the two `.fds` files are byte-identical. The LLM stayed loaded on GPU1 throughout. On GPU1 a 4-second, 60 fps, 960x400 master-ice film (240 direct frames, width 1e-35 to 1e-49) completed successfully, every frame on the GPU zone route. The `fd` report records 4.833 seconds; wrapper wall time was 5.77 seconds. One native 3840x1600 landing frame at ss1 took 0.516 seconds for the kernel including setup, 0.730 seconds for the reported whole film, and 1.62 seconds including process startup. All tests were limited to CPU cores 0 and 1, two requested render threads, low priority, and hard timeouts. No desktop windows were opened or services stopped.

A two-frame 320x180 lossless-film comparison against the CPU path with exact BLA tolerance passed `fd filmcheck`, with 100% of pixels within one RGB level in both frames. A separate stricter sample comparison at width 2e-48 failed its aggregate check: 11 of 57,600 samples differed between interior and unresolved (no escaped/interior reversals). Both display as interior under the film settings, but numerical identity with the CPU is not established. This is a successful supported-zone GPU test, not a direct speedup comparison with October 19's unsupported period-2287 target, nor a full 30-second native-resolution ss2 render. The source selects one adapter/device per renderer; these results do not show automatic pooling of two GPUs or a dual-GPU speedup.

**Limitations:** Sample timings are cold/shared-host observations, not controlled card-vs-card benchmarks. `filmcheck` covered two frames, not all 240 against CPU. ss1 was explicit; no full-quality ss2 estimate is justified. No simultaneous two-render throughput test or original-target performance measurement was made. The GPU1 LLM remained running. No changes to upstream code were made.
