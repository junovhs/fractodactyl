# Zone products

`v0-core.zone` is generated by the Rust `fd zone` producer from the exact first
centre in `bench/path-atlas-v0.txt`, with `patch_root`, `node`, `leaf`, `mid_*` and
`ref` records removed. It deliberately retains the small deep-zone map for benches
and loader tests. Independent old Python zone/frame fixtures live under
`crates/fd-cli/tests/fixtures/zones`; do not replace those with Rust output.

For the complete locally generated product (including tail atlas and mid band):

```bash
mkdir -p data/zones
read -r re im _ < <(awk '!/^#/ && NF {print; exit}' bench/path-atlas-v0.txt)
fd zone "$re" "$im" -o data/zones/v0.zone
```

`data/zones/v0.zone` has historically been generated locally, not committed. The
CLEA-02 regeneration is delivered as
`target/clea02-evidence/data/zones/v0.zone`, outside its disposable issue worktree.
`target/clea02-evidence/before` preserves the pre-change core and full fixture
zones. `scripts/check/CLEA-02.sh` compares all six 480x270 PROB-08 frames from old
and regenerated core/full zones through `fd render` and `fd compare`.
