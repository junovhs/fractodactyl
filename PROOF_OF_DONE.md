# Proof of done: distinguish discovery work from audited confirmation

**The historic 10/10 audit applies to formal confirmation; it is not a prohibition on exploratory mathematics.** See [METHOD.md](METHOD.md) and [PRIOR_ART.md](PRIOR_ART.md). Historical R-001–R-008 used a nine-box audit; preserve that fact.

## Two separate statuses

- `EXPLORATORY: YES`: a concrete new mathematical construction/prediction was examined by an actually executed numerical calculation or symbolic derivation; equations, inputs, observations and limitations are recorded. A preregistered P/PA pair and full literature dossier are **not needed**. Such results can be useful, but are not formal confirmation, independently reproduced benchmarks or validated novelty. Use `POD: NO` until the strict ten checks are satisfied.
- `POD: YES` (confirmatory): all ten checks below are satisfied for a specific frozen claim. A failed hypothesis can be `POD: YES` if the protocol and evidence are complete. `POD: NO` must not erase executed exploratory evidence.

Do not fake an exploratory run merely to make a session look productive, and do not avoid an informative safe cheap run because it cannot achieve 10/10 yet.

## Formal confirmation — 10/10 checklist

- [ ] **P-ID and pretest claim:** ≤150-word P-card, clear frozen accuracy/cost/capability gate, and prior exploratory tests honestly disclosed.
- [ ] **External prior art searched before the confirmatory run:** linked same-commit P/PA file with three actual external searches (mechanism, use, specialist rival), dated source links, reviewed primary material, known ingredient and precisely new extension/evaluation question, class and `TRIAGE: EXTEND/PROCEED/EVALUATE`; Git read-back verified. A retrospective dossier cannot satisfy this check.
- [ ] **Exact case:** equations, domains/initial conditions, seed, sample count, precision, event/class definitions and oracle target are fixed.
- [ ] **Fair relevant comparator:** strongest accurate same-math/specialist method for a performance claim, or an explicit reason no speed comparator is germane to a mathematical claim.
- [ ] **Executed observations:** actual numeric/symbolic outputs are archived or reconstruction details sufficient; interruptions and missing raw evidence explicitly identified.
- [ ] **Accuracy checked before cost:** independent worst error, relevant derivatives/event classifications, failure/abstention, or transparent reason an accuracy measure does not apply.
- [ ] **Cost accounted for:** real cold/setup, warm and amortized/repeated timing when performance is claimed, or `NOT RUN` with justified gate/no performance claim.
- [ ] **Two-part judgment:** each original frozen gate with actual measured units, separately the smaller true effects, utility and follow-up decision; no invented universal speedup threshold.
- [ ] **Scope and provenance:** known mathematical ingredients, what specifically exceeds them, uncertainty, exact limits and `REPORTED/REPRODUCED/CERTIFIED` and proof status truthfully reported.
- [ ] **Graph/Git verification:** R-card, parent P-card, INDEX/MAP and material FRONTIER changes consistent; committed files read back on only this lab branch. If Git write or verification failed, unchecked.

`POD: YES` only after *all ten* are checked; otherwise `POD: NO`, even if a useful experiment was run. No forced P/R or checklist applies to a literature-only candidate not tested.

## What the labels cannot prove

`GATE: PASS` does not prove mathematical novelty. `REPRODUCED` requires independent rerun-ready artifacts and actual rerun; `CERTIFIED` requires auditable enclosure/proof. A known technique may be an ingredient of an original method, but mere repackaging is not originality. The strongest benchmark is a reality check, not necessarily a target to outrun. No formal proof or speed claim follows from empirical agreement alone.

Preserve R-007's original ≥3× failure and R-008's scoped reported 1.209× synthetic gain simultaneously. The 1990 converter precedent changes novelty interpretation, not the reported timing. The P-083/R-009 known-method benchmark remains historical evidence, not a reason to outlaw useful follow-on mathematical questions.
