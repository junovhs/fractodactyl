# P-080 · Guarded PWM Taylor kick versus exact return

**Status:** KILL q=4 accuracy (not speed economics) · **Parent:** [P-030](P-030.md) · **Priority:** 1

**Question:** Can a guarded degree-four duty-cycle Taylor return accelerate two-state buck-converter sweeps?

**Mechanism:** For switched `x'=Ax+b`, use a centered polynomial for the exact one-period input kick; clip PWM duty and classify saturation branches.

**Value:** Reusable parameter-dependent maps in sampled-data converter design.

**Fair opponent:** Compiled exact matrix-exponential return with the same caching and matrices.

**Probe:** `A=[[0,-1],[1,-0.5]]`, on-input `b=(1,0)`, off-input zero, period `T=0.3`; `d=clip(0.5+0.6(0.5-v)+p,0.2,0.8)`. Seed 20261012; 128 independent triples `i∈[.15,.35],v∈[.35,.65],p∈[-.35,.35]`; 32 periods.

**Gate:** Versus independent matrix-exponential oracle: maximum final-state infinity-norm error ≤1e-7, **zero** duty-regime disagreements; then ≥3× cold end-to-end, including chart construction and compilation. Otherwise **KILL**.

**Next:** If killed, test guarded event-time sensitivities (not another easy fixed-event fit).
