# P-060 · Direct composition at a repelling Mandelbrot cycle

**Status:** UNTESTED · Parent: R-004

**Question:** Can repeated composition of a fixed-degree polynomial return outperform the existing Koenigs jump on a *repelling* Mandelbrot cycle, with verified state, parameter derivative and validity radius?

**Mechanism:** Power the local return operator by truncation/re-expansion instead of constructing/inverting a Koenigs coordinate.

**Fair opponent:** Fractodactyl's existing guarded Koenigs jump and the same-math direct return evaluator.

**Probe:** One existing period-2 or period-197 chart; double precision first, independent MPFR points, construction cost included.

**Kill:** Any accuracy/domain failure, or cold gain under 3× over the best same-math operator.

**Warning:** The contracting toy oscillator's 5.27× cannot be transferred as a performance prediction.
**Scope note:** The 3× gate is P-060-specific. Subthreshold accurate speedups still count as findings; test realistic reuse separately under [METHOD](../METHOD.md).
