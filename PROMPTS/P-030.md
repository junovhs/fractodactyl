# P-030 · Automatically guarded switching return maps

**Status:** UNTESTED · Parent: R-004 · Priority 1

**Question:** Can one compiler split state/parameter space by switching-event itinerary, build accurate local return maps, and accelerate repeated design sweeps of a small power-converter model?

**Mechanism:** Detect events, partition validity regions, generate parameter-dependent maps, and abstain when an error bound fails.

**Fair opponent:** Optimized event-aware compiled integration, cached maps, polynomial composition, and established periodic operating-point methods.

**Probe:** A two-state switched model; 100–1,000 parameter/state combinations, 16–64 periods in Python/Numba.

**Kill:** Any wrong event branch, worst state error above 1e-7, or cold speed-up below 3× over the strongest accurate rival.

**Next:** Only promote to physical modeling and certification if the tiny probe passes.
