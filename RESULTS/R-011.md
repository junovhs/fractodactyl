## Question and falsifier

Can R-010's nonsequential exact-z0 chart seed be enclosed in finite arithmetic without reverting to a full serial orbit/error-propagation pass? Can direct continuation remain certified beyond the very conservative uniform 4^L bound? Falsifiers: root failure, error admission exceeding 1e-7, failure to enclose a separate high-precision serial IVP, or a compressed estimate worse than a pathwise scan. Cold economic advantage, broad transfer and novelty are **not** presumed.

Known ingredients: the classical Poincare/Koenigs repelling-point functional equation; truncated polynomial residuals; outward-rounded interval arithmetic; affine error-majorant composition/geometric sums; and interval forward iteration. Prior context and adjacent time-parallel literature are [R-010](R-010.md), [P-051](../PROMPTS/P-051.md), and [van der Hoeven (2025)](https://www.texmacs.org/joris/lagrange/lagrange.html). Their individual techniques are not claimed new. The proposed composition below is a **testable extension**, not a cleared originality claim. No new three-search confirmatory dossier was performed.

## Construction and correctness argument

Use the exact real IVP z_0=0, z_(j+1)=z_j^2+c, z_2=c^2+c, the positive repelling fixed point alpha=(1+sqrt(1-4c))/2, and lambda=2alpha>1 (tested c<=-3/4). For q>=1 define

    phi_q(t)=sum_(k=1)^q a_k t^k,  a_1=1,
    a_k = (sum_(i=1)^(k-1) a_i a_(k-i))/(lambda^k-lambda).

For an *exact* choice of alpha and a_k, certify a real root t_2 of phi_q(t_2)=z_2-alpha: enclose all coefficients and target, find a dyadic [l,u] for which phi_q(l)<z_2-alpha<phi_q(u) with interval inequalities, and show phi'_q([l,u])>0. Thus a unique exact root exists **inside** the computed interval, independent of the numerical Newton guess used to locate it. The chart candidate is w_j=alpha+phi_q(lambda^(j-2)t_2) for j>=2. It is anchored to the original exact z_0 via exact z_2, not to a freely shadowing orbit. In principle e_2=z_2-w_2=0; the implementation conservatively carries a positive outward bound E_2 from interval evaluation.

Let L=|lambda|, u=upper|t_2|, A_k=upper|a_k| and

    D_k=sum_(max(1,k-q)<=i<=min(q,k-1)) A_i A_(k-i), q<k<=2q.
    R_j=sum_(k=q+1)^(2q) D_k (u L^(j-2))^k.

The exact polynomial functional-equation defect has modulus <=R_j. For e_j=z_j-w_j,

    e_(j+1)=(2w_j+e_j)e_j-r_j.

With eta=1e-7, a valid bootstrap step has |e_(j+1)| <= B_j E_j+R_j when E_j<=eta and B_j=2 upper|w_j|+eta. The final reported point is the **lower dyadic endpoint** y=W_n.lo of an outward chart evaluation W_n; a sufficient tested output gate is

    E_n + (W_n.hi-W_n.lo) <= eta,

in addition to all bootstrap checks. This accounts for interval coefficient/input/inversion/evaluation uncertainty as well as truncation.

**Compressed early prefix.** Choose rho=1/64. Let J be the largest integer 0<=J<=n-2 with T_0:=u L^J<=rho (or J=0 if the initial chart argument is larger); j_0=2+J. Put

    M_0=upper|alpha|+sum_(k=1)^q A_k T_0^k;  B_0=2M_0+eta.
    S_J(r)=sum_(h=0)^(J-1) r^h.
    E_(j_0) <= B_0^J E_2
       + sum_(k=q+1)^(2q) [D_k T_0^k / L^k] S_J(B_0/L^k).

Proof: throughout 2<=j<j_0, |w_j|<=M_0 and R_j is bounded by the polynomial defect; unroll E_(j+1)<=B_0 E_j+R_j and reindex the geometric series backward from j_0. All factors are nonnegative, so outward upper rounding preserves the inequality. Since B_0>1 and R_j>=0, an admitted terminal early bound also controls each preceding bootstrap error. Compute S_J by associative doubling of (A^m,B^m,S_m), with S_(m+n)=A^n S_m+B^m S_n; this avoids cancellation and costs O(log J) arithmetic per k, not J chart-orbit evaluations. For j>=j_0 use explicitly enclosed chart W_j and R_j for the remaining K=n-2-J steps, checking each bootstrap.

**Certified direct tail.** Only after chart admission, take

    Z_n=[W_n.lo-E_n, W_n.hi+E_n],
    Z_(j+1)=square_interval(Z_j)+C

with outward-rounded C enclosing the exact c, and test width(Z_(n+L))<=eta before reporting the lower endpoint. This gives a fixed-IVP enclosure without using a uniform 4^L amplification factor. A long direct tail is nevertheless sequential work.

All claimed inclusions depend on the interval arithmetic implementation being correct. This scratch executable was not archived or independently audited; the result therefore remains REPORTED/POD NO, not a promoted CERTIFIED solver.

## Executed methods and arithmetic provenance

**Actually run:** Python 3.13.5, mpmath 1.3.0, deterministic cases below. Code executed in the Chat compute container at /tmp/dtl_probe.py (not committed; this temporary path is not an independently retrievable artifact). mpmath supplies a *guess only* for t_2, with 16 Newton steps; each acceptance uses a separate strictly signed, monotone interval root bracket. Exact c values are rationals. Independent accuracy oracle: serial z_(j+1)=z_j^2+c from z_0=0 in mpmath at **at least 450 decimal digits**, with direct recurrence and no chart or shooting correction; this oracle is numerically independent by algorithm but not by arithmetic library.

The certified enclosure code uses **Python arbitrary-precision integers at fixed dyadic grid 2^(-p)**, not unverified mpmath rounding: each interval endpoint is an integer. Addition/subtraction are exact on grid endpoints; multiplication takes floor/ceil of all four endpoint products divided by 2^p; division takes directed floor/ceil of the four corner quotients (numerator times 2^p), rejecting zero-containing divisors; square uses interval sign cases; sqrt uses integer isqrt of endpoint times 2^p and exact-square detection; powers are outward repeated squaring; positive geometric sums use the above associative doubling. Coefficients, alpha, lambda, chart evaluation, defect, split, error envelope and tail all use those operations. The root bracket initially has radius 2^(-p+20) around the tentative Newton guess, doubled until strict interval signs and phi'_q>0 verify it. The split J uses binary search on upper(u L^J)<=1/64. The oracle precision is raised above 450 digits if needed.

**Independent arithmetic spot checks in the same compute container:** 10,000 deterministic exact-Fraction corner/enclosure tests of interval multiplication, division when defined, and squaring; 9,999 exact integer-square-root enclosure tests; 80 nontrivial geometric-sum identities at short lengths. All passed. These property checks are not a formal audit of the entire program.

## Interpretation, obstruction and next falsifier

**Supported exploratory result:** a signed interval root bracket plus a localized, algebraically collapsed error budget gave finite-arithmetic enclosure of a nonsequential seed from the *original* fixed initial condition, and a direct interval tail sharply outperformed a worst-case uniform error envelope. The early prefix can be **certified** with J=124 via an O(q log J) positive geometric calculation, rather than iterating all 124 chart/error interfaces; this is not an O(1) cost claim. The seed calculation never constructs z_3,...,z_131. All results are subject to implementation audit, and no external validation pack was committed.

**Strong limits:** severe chart-domain restriction (rejection just two steps beyond the good near-minus-two seed); broad-domain cases allow only short horizons; precision cost and coefficient construction are not free; a 102-step direct tail is still serial; independent multiple-shooting corrections were NOT RUN; negative fixed-point inverse branches abstained. No production use, timing, parallel hardware, industrial transfer, novelty priority or superiority to specialist MPFR/series-composition methods has been established. Historical P-051's frozen 256–4096-step, 1k–10k-bit accuracy/cost gate stays UNTESTED. Accuracy gate here is exploratory and not a retroactive modification to P-051.

**Next discriminating step:** audit/reconstruct the interval algorithm independently; test other repelling cycles and well-specified hostile parameters; find the maximum useful *nonsequential* reach at equal certification strength; compare real **cold**, reuse, interval preparation, series construction and direct-tail costs with a correct optimized serial high-precision method, with an appropriate three-query prior-art/preregistered P/PA step before any confirmatory claim. If the only long-range domain is an exponentially near-preperiodic family, classify it as such rather than claiming a general solver.
