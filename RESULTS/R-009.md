## Frozen question and gate

P-083 registered a quadratic local inverse event-time predictor plus up to two Newton steps, with continuation/fallback when the guard residual exceeds `1e-12` or the update is unsafe, versus the strongest cached, compiled closed-form-flow safeguarded-Newton and bracketed-root competitors. It required **maximum final-state error ≤1e-7**, event-time error ≤1e-9 and **zero wrong event classes** on an independent holdout. It requested *measurement* of cold, warm and savings but imposed **no numerical speed threshold**. A correct small warm gain is not automatically a useful cold saving.

## Exact model and reconstruction

Two continuous states, one threshold-controlled event per period: `x' = -0.8 x + c`, `y'=0.55 x-0.6 y+d`. Start each period in ON `(c,d)=(0.2,1.4)`, switch on the **first upward crossing** of `g=y-(0.25+p)=0`, then use OFF `(c,d)=(-0.1,-0.8)` through `T=0.8`. If initial `g>=0`, do not count a crossing and transition immediately; if final-ON `g<=0`, no switch before period end. The sampled domain's ON guard is monotonically increasing at crossings; generic grazing, multiple-crossing and chatter regimes were **not** explored.

Exact mode flow for any constant `c,d` and elapsed `t`:
`x_eq=c/0.8; x(t)=x_eq+(x0-x_eq)exp(-0.8t)`;
`y(t)=y0 exp(-0.6t)+(.55*x_eq+d)(1-exp(-0.6t))/.6 + .55(x0-x_eq)(exp(-0.6t)-exp(-0.8t))/.2`.
Period update: exact ON flow to root `tau`, exact OFF flow to `0.8-tau`. Candidate approximates first `tau` using the positive root of `g0+g'0*t+0.5*g''0*t²=0`, with `g'0=.55x-.6y+1.4`, `g''0=.55(-.8x+.2)-.6*g'0`, then 2 safeguarded Newton attempts, then up to 24 fallback Newton/bisection corrections until `abs(g)<=1e-12`; bracket initially `[0,.8]`. Opponent uses exactly the same propagation, bracket and stopping condition but starts at the midpoint with up to 16 safeguarded Newton steps (and 24 follow-on if necessary). This is a *same-flow, compiled, cached* comparison, not a naive Python `solve_ivp` runtime comparison.

Accuracy holdout: seed **20261030**, 128 independent trajectories, 16 periods, `x0 ~ U[-.05,.30]`, `y0 ~ U[-.15,.08]`, `p ~ U[-.08,.08]`; NumPy `default_rng` generates variables in that order. Reference uses **SciPy Brent bracket roots** (`xtol=1e-14`) on the analytic closed-form ON flow and exact OFF update. It is algorithmically independent of the Newton roots but **not an independent physical integrator**, so error evidence is scoped. Warm-benchmark inputs use seed **20261031**, same input construction and 128×16 state/event updates per invocation. The timing batch repeats the pre-generated input **128 calls**, i.e. **262,144 updates** per timing observation, not 262,144 independent input draws. CPU AMD EPYC 9V74, Linux 6.18.44 x86_64, Python 3.13, NumPy 2.3.5, SciPy 1.17.0, Numba 0.65.1, float64; `time.perf_counter_ns()`.

Raw **cold** new-process observations in the same order (ms): `C 1164.115876; B 1122.827278; B 1136.153697; C 1316.463299; C 1158.513657; B 1089.567723`. Host noise and the unusually slow fourth sample warrant caution; only three observations each. Both arms execute 128 calls after compilation in warm samples, and all 128 calls including JIT in cold samples. External Python import/input generation excluded equally.

Empirical **GATE: PASS** (state/time/class), **opportunity: CONDITIONAL**, not an end-to-end production win. The candidate *always* required further Newton fallback after its two predictor corrections; most of its advantage is fewer total root iterations, **not skipping root location**. A competing quadratic-start optimized Newton implementation would likely erode the method's distinctiveness: both use ordinary root-finding.

## Post-result research-priority correction (owner direction, 2026-10-12)

The [pretest prior-art review](../PRIOR_ART/PA-P-083.md) had already shown that event-time localization was established. The experiment nonetheless pursued a standard warm-start versus root-solver speed contest. **That was the wrong autonomous research selection**, independently of its legitimate numerical observations. Under the revised [prior-art policy](../PRIOR_ART.md) the appropriate step was **cite, STOP and PIVOT to another mathematical mechanism before computation**. Preserve the frozen original numerical gate, raw reported results and historical POD, but **do not make a follow-on known-method performance benchmark the active discovery goal**. This is a posttest priority correction, not retroactive preregistration or an accuracy revision.

## Research decision

**CONDITIONAL:** a measurable warm synthetic gain survives controlled Numba execution, but the *cold end-to-end* case loses, and all 2,048 candidate events need fallback beyond its original two-step target. There is no evidence of industrial, general-hybrid, or cold deployment acceleration. **Next discriminatory question:** in a separately preregistered P-card with executed literature audit, test whether cheap coarse event-time certificates can safely avoid most root iterations, or whether an already optimized root solver closes the gap. Test harder initial states, event absences and near-tangent crossings as correctness threats before pursuing transfer. Do not pursue a higher polynomial degree without evidence.
