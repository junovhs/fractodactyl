# R-002 · Koenigs broad-domain accuracy failure

**Date:** 2026-10-12 · **Parent:** [P-020](../PROMPTS/P-020.md) · **Evidence:** REPORTED · **Decision:** KILL broad-domain version.

**Toy model:** Scalar periodically forced dissipative oscillator, (x'=-0.006x-0.15x^3+0.18\cos(t)), sampled every (2\pi). Build an eighth-degree local Koenigs jump from a fitted return map.

**Predeclared gate:** Worst state error ≤1e-7 before timing; fair opponent can evaluate or compose the same map.

**Reported observations:** Broad-chart 1-period Koenigs maximum state error ~4.09e-4; fitted map ~3.05e-9; RK4 versus DOP853 ~1.87e-9 (32 independent starting states). A correction to the Newton-inverse derivative did not rescue the broad-domain jump.

**Decision:** No speed-up is relevant because accuracy failed by ~4,000× its target. A successful fit of the one-period map is not evidence that its Koenigs extrapolation is valid over a broad domain.

**Limitations:** Empirical samples only; no interval theorem, complete holdout file or executable committed.
