## Construction

For z_0=0, z_(n+1)=z_n^2+c, z_2=c^2+c, alpha=(1+sqrt(1-4c))/2, lambda=2alpha, use phi_q(t)=sum_(k=1)^q a_k t^k with a_1=1 and a_k=sum_(i=1)^(k-1) a_i*a_(k-i)/(lambda^k-lambda). Solve phi_32(t_2)=z_2-alpha by 20 Newton iterations starting at z_2-alpha. Then w_n=alpha+phi_32(lambda^(n-2)*t_2). Let d_k=sum_i a_i*a_(k-i) for 32<k<=64 and R_j=sum_(k=33)^64 |d_k| |t_2*lambda^(j-2)|^k. Starting E_2=|z_2-w_2|, advance E_(j+1)=(2|w_j|+10^-7) E_j+R_j. Compare to **separate serial** high-precision z recurrence. An exploratory step is marked PASS only if BOTH E_n<=10^-7 and |z_n-w_n|+E_n<=10^-7; this strict redundant empirical guard is not R-011's outward-dyadic endpoint test. Once E exceeds the bootstrap tolerance, later values are **invalid as error certificates**, regardless of printed numbers.

## Interpretation and next falsifier

All 14 ordinary decimal c values stop at n<=10 for this q=32 positive-fixed-point direct chart; small parameter changes can shift the last admitted step. This provides incremental negative evidence against a broad-domain *direct positive-fixed-point chart*, but does **not** rule out higher q, other repelling cycles, alternate inverse branches, chart reanchoring, or validated multiple shooting. It does not demonstrate asymptotic cost benefit or novelty. The apparent giant errors past first failure are **unadmitted values**, not certified trajectory errors.
